Procedural World Lab

A world grown from a seed

Explore rivers, hills and forests. Trees and grass are generated in Rust; animated animals roam the map.

Requires a desktop browser with WebGPU.

Choose a seed and start exploring.

Controls & demo details

W / S Move   A / D + mouse Turn   Shift Run   V First person / follow   B Overview   Wheel Zoom   Esc Release mouse

R Return to start   L River bank   G Ford   F3 Resource panel   F4 Map layers

This browser demo keeps nine chunks nearby and uses the same animated animal models as the desktop app. Desktop exploration keeps a wider area. CPU / process memory / GPU usage measurements are unavailable in the browser; frame rate and generated mesh estimates remain available.
